BIX trips hold passenger BIX (85/15 on completion), cash trips debit the commission as BIX gas from the driver on accept (bix_bixgo_bix_delta in bix_asset_balances); RPCs set a local bixgo.rpc flag so the settle guard only blocks direct client writes.
- BIXGO dispatch: Food/Send/Mart are real bookings visible only to approved moto drivers via bixgo_driver_jobs; passengers rate completed trips once via bixgo_rate_trip; driver readiness checklist is a client hint, the server still enforces balances on accept.

- BIXGO direct payments: drivers store their own QR/bank via bixgo_driver_set_pay; QR/Bank trips pay the commission as BIX gas on accept like cash, riders see payee details only via bixgo_trip_payee, and a trigger blocks completion until the driver confirms receipt (bixgo_trip_confirm_paid).
